- 自动保存仅提交本次运行选项，保留尚未应用的代理草稿；跨页面的保存由应用统一排队。
- 手动保存将代理地址、协议、端口与档案身份一起提交，防止后台自动切换后改错档案。

- 无效更新清单不再覆盖已经校验的更新包与清单；网络和内容错误共用缓存保留逻辑。
- 0ms 握手不会退回长连接存活时长，且参与中位数与平均值；未完成连接不提前计入样本。

回归使用临时文件、本地模拟服务器与独立页面后端，不结束正在使用的 Codex；AGENTS.md 与 design 保持本地忽略。
